# Development

## For Developers & Contributors

**GravityRoute** uses a local Tailwind CSS build system alongside Vanilla CSS and Alpine.js for maximum performance and zero bloat. CSS is pre-compiled and included in the repository, so you can run the project immediately after cloning.

### Quick Start

```bash
git clone https://github.com/samoba-islam/gravityroute.git
cd gravityroute
npm install  # Automatically builds CSS via prepare hook
npm start    # Start server on http://localhost:8080
```

---

### Build & CSS Tooling

```bash
# Build production bundle / CSS
npm run build

# Watch CSS during styling changes
npm run watch:css

# Full dev mode: watches CSS and auto-restarts Node.js server
npm run dev:full
```

**Style Architecture:**
- `public/css/src/input.css`: Source CSS with Tailwind directives & custom design tokens (edit this).
- `public/css/style.css`: Minified production output (auto-generated by `npm run build`).
- `tailwind.config.js`: Theme extensions, color palette (`neon-purple`, `neon-cyan`, `space-900`, etc.), and DaisyUI plugins.

---

### Admin & Auth CLI Utilities

```bash
# Reset administrator password from terminal
npm run reset-password <new_password> [username]

# Add Google account via OAuth
npm run accounts:add

# Add account on headless server (no browser)
npm run accounts:add -- --no-browser

# List active accounts and quota status
npm run accounts:list

# Verify credentials and tokens
npm run accounts:verify
```
