Client Setup & Integration Guide

Connect any OpenAI-compatible or Anthropic-compatible tool, CLI, or library to GravityRoute Proxy using your generated API keys.

Auth Header Bearer & x-api-key

Model IDs: Use Native Backend Models or Standard OpenAI Aliases

Querying GET /v1/models returns the exact active native models list identical to Anthropic compatibility (skipping any models marked hidden in Models settings). Clients can directly use any native model ID (e.g. claude-sonnet-4-6, claude-opus-4-6-thinking, gemini-2.5-pro, gemini-2.5-flash) or standard OpenAI model aliases (gpt-4o, gpt-4o-mini, o1).

1. OpenAI SDKs & Compatibility Layer
Python (openai package) 
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="ag-sk-your-generated-key"
)

# Use any native model ID or OpenAI alias (e.g. gpt-4o)
response = client.chat.completions.create(
    model="claude-sonnet-4-6",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain quantum computing in one sentence."}
    ],
    stream=True
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()
Node.js / TypeScript 
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://localhost:8080/v1',
  apiKey: 'ag-sk-your-generated-key'
});

async function main() {
  const stream = await openai.chat.completions.create({
    model: 'gpt-4o', // or native 'claude-sonnet-4-6'
    messages: [{ role: 'user', content: 'Say hello!' }],
    stream: true,
  });

  for await (const chunk of stream) {
    process.stdout.write(chunk.choices[0]?.delta?.content || '');
  }
}

main();
cURL / Direct HTTP Request 
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ag-sk-your-generated-key" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello GravityRoute!"}],
    "stream": false
  }'
2. IDEs & Coding Assistants (Cursor, Continue.dev, LibreChat)
Cursor IDE Configuration OpenAI Provider
  1. Open Cursor Settings → Models.
  2. Turn on OpenAI API Key override.
  3. Set Base URL to http://localhost:8080/v1.
  4. Enter your API key: ag-sk-....
  5. Under model list, type any native ID (e.g. claude-sonnet-4-6) or select gpt-4o.
Continue.dev (config.json) 
{
  "models": [
    {
      "title": "GravityRoute Sonnet",
      "provider": "openai",
      "model": "claude-sonnet-4-6",
      "apiBase": "http://localhost:8080/v1",
      "apiKey": "ag-sk-your-generated-key"
    }
  ]
}
3. Anthropic Messages Protocol & Claude Code CLI

Set environment variables in your terminal profile (~/.zshrc, ~/.bashrc, or Windows PowerShell):

export ANTHROPIC_BASE_URL="http://localhost:8080"
export ANTHROPIC_API_KEY="ag-sk-your-generated-key"
Anthropic Messages API cURL 
curl http://localhost:8080/v1/messages \
  -H "content-type: application/json" \
  -H "x-api-key: ag-sk-your-generated-key" \
  -H "anthropic-version: 2023-06-01" \
  -d '{"model":"claude-sonnet-4-6","max_tokens":50,"messages":[{"role":"user","content":"Hello"}]}'
